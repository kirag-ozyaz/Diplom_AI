# Результаты проверки комплекта

Проверка выполнена 8 ноября 2026 года, Europe/Astrakhan (UTC+4).

## Фактический прогон

1. Получены актуальные `data/extracted/1.1.md` … `1.9.md` с Drive.
2. Для ресурсов использованы 66 локальных файлов из ранее полученного корпуса;
   их имена сопоставлены со свежим содержимым папок Drive. Ресурсы не скачивались
   повторно побайтово. На машине пользователя проверка использует именно его файлы.
3. Для V2 использована локальная копия 46 JSONL/3060 чанков; имена и размеры
   сопоставлены со свежим списком Drive. Это не утверждение о свежем скачивании
   или сравнении всех удалённых файлов по контрольным суммам.
4. ZIP распакован в отдельный каталог. Оттуда выполнены prepare, check, merge
   без применения, check плана, merge с явным приоритетом девяти глав и check результата.
5. Сравнены SHA-256 до/после у 795 входных файлов и файлов старого конвертера:
   все совпали. Старый каталог конвертера не входит в новый ZIP.
6. Вывод каждой из шести команд дословно совпал с записанным ею UTF-8 логом.

Получено:

* 9 ручных документов, 456 собственных пунктов, 95 контекстных блоков;
* 552 ручных чанка (один длинный блок разделён на две части без потери текста);
* все 9 Markdown восстановлены целиком; исходные байты, включая BOM/CRLF, сохранены;
* план без применения содержит 0 активных чанков;
* объединённый результат содержит 46 документов и 3146 чанков;
* из них 552 взяты из ручных глав 1.1–1.9, 2594 — из остальных 37 документов V2;
* все 466 заменённых чанков V2 остаются в архиве;
* проверка объединения учла все 3612 входных строк (552 + 3060);
* ссылки на ресурсы заменены обратимо, остальные символы исходного текста сохранены;
* база данных, активный индекс и исходные корпуса не изменены.

## Изолированные тесты

39 тестов прошли. Полный журнал — `tests.log`.
Проверяются BOM/CRLF, формулы и таблицы, целостность ресурсов, заголовки,
границы кода/формул, повтор и пропуск пунктов, неоднозначный Scope/документ,
недостающие файлы, абсолютные/опасные пути, выход через symlink,
неподдержанные схемы ссылок, слишком большой неделимый блок,
попытка перезаписи/пересечения папок, изменение V2 после подготовки,
план без активных чанков, явный приоритет, целые документы,
изменение/добавление файлов после импорта и стабильность ID.

Фактическая среда прогона — Python 3.13.5 на Linux.
Синтаксис каждого модуля отдельно проверен парсером с грамматикой Python 3.9.
Запуск в Windows/Python 3.9 на компьютере пользователя здесь не выполнялся.
Новых зависимостей, кроме стандартной библиотеки Python 3.9+, нет.
