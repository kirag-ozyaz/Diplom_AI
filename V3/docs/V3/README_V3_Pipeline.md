# RAG V3 Pipeline — Документация (Этап 5)

## 1. Структура папок в etap5
- `etap5` — рабочая директория 5-го этапа.
- `trash` — папка для убранных устаревших и дублирующих файлов.
- `V3` — папка нового гибридного контура V3 и готовых Jupyter-ноутбуков.

## 2. Зафиксированные документы по стратегии
- Стратегия дообучения RAG-системы (Fine-Tuning зафиксирован как Plan B — резервная гипотеза).
- Пайплайн и скрипты дообучения RAG-системы (Этап 5).

## 3. Модули контура V3
- `v3_hybrid_retriever.py` — гибридный поиск (BM25 + E5 Dense Embeddings + Reciprocal Rank Fusion + BGE Re-ranker v2 m3).
- `v3_rag_pipeline.py` — генерация ответа языковой моделью (Qwen2.5 14B / Ollama) с форматированием цитат ПУЭ.
- `v3_evaluation.py` — автономный расчет метрик качества поиска (Hit@k, MRR, nDCG) и отклика LLM.

## 4. Итоговые ноутбуки
- `stage5_final_pipeline_notebook.ipynb` — Ноутбук №1 (Финальный): функциональный пайплайн с интерактивным окном «вопрос → поиск → ответ со ссылками на ПУЭ».
- `stage5_experiments_notebook.ipynb` — Ноутбук №2 (Экспериментальный): сводный сравнительный анализ Опытов 1–5 с графиками и визуализацией результатов.
