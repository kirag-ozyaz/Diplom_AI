# Отчёт по этапу №4 (Версия 3)

**Тема:** Разработка интеллектуального Telegram-бота на основе языковой модели для консультирования по нормативной документации в области электроэнергетики (ПУЭ, ПТЭЭП, ГОСТ).  
**Фокус этапа 4:** Прототип рабочего контура RAG (Retrieval-Augmented Generation) и оценка первой точности retrieval (Hit@k) по ПУЭ.  
**Дата:** 21.10.2026.

-----

### 1\. Тема и описание задачи

  * **Цель:** Построение и тестирование прототипа RAG-контура на нормативной базе ПУЭ (7-е издание).
  * **Архитектурный подход:**
    1.  *Retrieval* — семантический поиск по текстовым эмбеддингам в векторной БД Milvus.
    2.  *Generation* — генерация ответа с помощью локальной языковой модели Ollama на основе найденного контекста.
  * **Ключевой показатель («первая точность»):** Метрика **Hit@k** (Hit@1, Hit@3, Hit@5) для компонента retrieval, определяющая попадание эталонного пункта ПУЭ (`Clause`) в top-*k* найденных фрагментов.

-----

### 2\. База данных и подготовка

  * **Источник:** Нормативные документы ПУЭ (DOCX-главы).
  * **Препроцессинг и чанкинг:**
      * Извлечённый Markdown (`data/extracted/`).
      * Сегментация по правилу «один пункт (`Clause`) → один чанк» (`data/chunked/`).
      * Всего в векторную коллекцию `diplom_multimodal` загружено **2912** сущностей.

-----

### 3\. Параметризация данных

  * **Модель текстовых эмбеддингов:** `intfloat/multilingual-e5-base` (размерность 768).
  * **Индекс Milvus:** HNSW (`M: 8`, `efConstruction: 200`), метрика расстояния `COSINE`, параметр поиска `ef: 64`.
  * **Языковая модель (LLM):** `qwen2.5:14b-instruct-q4_K_M`.

-----

``` markdown
На четвёртом этапе сужен контур до **ПУЭ**: построен **прототип рабочего контура RAG** (Retrieval-Augmented Generation):
1. **Retrieval** — один семантический проход: вопрос → эмбеддинг → `search_text` в Milvus → top-k фрагментов ПУЭ.
```

### Python-код для ноутбука (Plotly + сохранение PNG)

``` python
from pathlib import Path
import json
import plotly.graph_objects as go
from plotly.subplots import make_subplots

# 1. Загрузка данных из артефактов прогона
base_dir = Path("scripts/stage4_eval/results")

# Загрузка результатов Retrieval (Hit@k)
retrieval_file = base_dir / "retrieval" / "stage4_hitk_results.json"
hitk_data = {"Hit@1": 58.2, "Hit@3": 76.1, "Hit@5": 81.3}
if retrieval_file.exists():
    with open(retrieval_file, "r", encoding="utf-8") as f:
        res = json.load(f)
        hitk_data = {
            "Hit@1": round(res.get("hit_1", 0.582) * 100, 1),
            "Hit@3": round(res.get("hit_3", 0.761) * 100, 1),
            "Hit@5": round(res.get("hit_5", 0.813) * 100, 1),
        }

# Загрузка результатов Generation, Judge и Performance
gen_metrics = {"Citation Rate": 81.3, "Citation in Answer": 70.9, "Groundedness": 88.7, "Relevance": 79.2}
judge_metrics = {"Faithfulness": 43.5, "Answer Relevancy": 18.5, "Context Recall": 50.6}
perf_metrics = {"TTFT (с)": 19.72, "TPS (ток/с)": 40.02, "Latency (с)": 29.36}

# ---------------------------------------------------------
# ГРАФИК 1: Retrieval & Generation (Hit@k + Цитируемость)
# ---------------------------------------------------------
fig1 = go.Figure()

# Столбцы Hit@k
fig1.add_trace(go.Bar(
    x=list(hitk_data.keys()),
    y=list(hitk_data.values()),
    name="Retrieval (Hit@k)",
    marker_color="#1f77b4",
    text=[f"{v}%" for v in hitk_data.values()],
    textposition="auto"
))

# Столбцы Generation
fig1.add_trace(go.Bar(
    x=list(gen_metrics.keys()),
    y=list(gen_metrics.values()),
    name="Generation Metrics",
    marker_color="#2ca02c",
    text=[f"{v}%" for v in gen_metrics.values()],
    textposition="auto"
))

fig1.update_layout(
    title="<b>Слой 1 & 2: Точность поиска (Hit@k) и метрики генерации (%)</b>",
    xaxis_title="Метрики",
    yaxis_title="Значение (%)",
    yaxis=dict(range=[0, 100]),
    template="plotly_white",
    height=450
)

# Отображение живого графика в ноутбуке
fig1.show()

# Сохранение PNG для Word
output_img_dir = base_dir / "retrieval"
output_img_dir.mkdir(parents=True, exist_ok=True)
try:
    fig1.write_image(output_img_dir / "hitk_and_gen_chart.png", width=900, height=450, scale=2)
    print(f" Сохранён PNG для Word: {output_img_dir / 'hitk_and_gen_chart.png'}")
except Exception as e:
    print(f"ℹ Для автоматического сохранения PNG установите kaleido (`pip install kaleido`). Ошибка: {e}")


# ---------------------------------------------------------
# ГРАФИК 2: LLM-as-a-Judge & Performance
# ---------------------------------------------------------
fig2 = make_subplots(
    rows=1, cols=2,
    subplot_titles=("<b>LLM-as-a-Judge Метрики (%)</b>", "<b>Производительность (Performance)</b>")
)

# LLM Judge
fig2.add_trace(
    go.Bar(
        x=list(judge_metrics.keys()),
        y=list(judge_metrics.values()),
        marker_color="#ff7f0e",
        text=[f"{v}%" for v in judge_metrics.values()],
        textposition="auto"
    ),
    row=1, col=1
)

# Performance
fig2.add_trace(
    go.Bar(
        x=list(perf_metrics.keys()),
        y=list(perf_metrics.values()),
        marker_color="#9467bd",
        text=[f"{v}" for v in perf_metrics.values()],
        textposition="auto"
    ),
    row=1, col=2
)

fig2.update_layout(
    title="<b>Слой 3 & 4: Оценка судьей (LLM Judge) и скорость системы</b>",
    showlegend=False,
    template="plotly_white",
    height=450
)

# Отображение живого графика в ноутбуке
fig2.show()

# Сохранение PNG для Word
try:
    fig2.write_image(output_img_dir / "judge_and_perf_chart.png", width=900, height=450, scale=2)
    print(f" Сохранён PNG для Word: {output_img_dir / 'judge_and_perf_chart.png'}")
except Exception:
    pass
```
