# Этап 4. Пакет отчёта: состав папки etap4

В папке лежат отчёт, приложение и два ноутбука, которые воспроизводят таблицы и рисунки отчёта по сохранённым результатам.

| Файл | Что это |
|---|---|
| `user_v10.15.docx` | отчёт: часть I (разделы 1-8, первая версия) и часть II (разделы 9-17, вторая версия); примеры работы в режиме вопрос-ответ - разделы 5.9 и 14.7 |
| `Prilozhenie_skripty_i_fajly_po_razdelam.docx` | приложение: скрипты и файлы по разделам |
| `Etap4_V1.ipynb` + `data_V1.zip` | ноутбук части I и его данные, описание в [Readme-4_V1.md](Readme-4_V1.md) |
| `Etap4_V2.ipynb` + `data_V2.zip` | ноутбук части II и его данные, описание в [Readme-4_V2.md](Readme-4_V2.md) |

## Быстрый запуск

**Google Colab.** Загрузить нужный ноутбук и выполнить все ячейки. Первая ячейка сама скачает свой архив данных по прямой ссылке и распакует его.

**Другой компьютер.** Скачать ноутбук и архив, распаковать архив рядом с ноутбуком (должна получиться папка `data_V1` или `data_V2`), затем:

```
pip install jupyter plotly pandas
jupyter notebook
```

Оба ноутбука уже выполнены, поэтому результаты видны и без запуска (в том числе в просмотре Google Drive через Colab).

## Откуда берутся data_V1 и data_V2

Папки собираются скриптами из репозитория, скрипты только копируют файлы:

- `scripts/stage4_eval/collect_data_V1.py` - для первой версии;
- `V2/scripts/collect_data_V2.py` - для второй версии.

Подробности в [Readme-4_V1.md](Readme-4_V1.md) и [Readme-4_V2.md](Readme-4_V2.md).
